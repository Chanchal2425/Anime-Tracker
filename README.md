# 🎬 Anime Tracker

A modern full-stack Anime Tracking web application built with **React**, **Django REST Framework**, and the **Jikan API**.

Track your favorite anime, manage watchlists, get AI-powered recommendations, save episode notes, view trailers, and monitor your anime watching stats — all inside a sleek modern UI.

---

# ✨ Features

## 🔐 Authentication
- User Registration & Login
- JWT Authentication
- Persistent Login Sessions
- Protected Routes

---

## 📺 Anime Management
- Add anime to watchlist
- Update watch status
- Track watched episodes
- Store anime ratings
- Delete anime entries

---

## 🤖 Smart Recommendations
- Genre-based recommendations
- Similar anime suggestions
- Time-based anime recommendations
- Trending/top anime picks

Powered by:

- Jikan REST API
- MyAnimeList data

---

## 📝 Episode Notes
- Save notes for episodes
- Personal anime journaling
- Episode-specific tracking

---

## 📊 Anime Statistics Dashboard
- Total anime tracked
- Completed anime count
- Watching / Dropped stats
- Average rating
- Completion percentage
- Watch streak system
- Total watch time

---

## 🎞️ Trailer System
- Embedded anime trailers
- Auto trailer fetching
- YouTube fallback search

---

## 🎨 Modern UI
- Responsive design
- Glassmorphism navbar
- Gradient buttons
- Animated navigation
- Dark anime aesthetic
- Sticky modern navbar

---

# 🛠️ Tech Stack

## Frontend
- React
- React Router
- Axios
- Context API
- CSS3

---

## Backend
- Django
- Django REST Framework
- Simple JWT
- SQLite

---

## External APIs
- Jikan API
- MyAnimeList Data
